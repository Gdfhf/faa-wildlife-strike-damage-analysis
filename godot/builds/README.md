# Godot Visualizer Build

The compiled Windows visualizer is distributed through the project's
GitHub Releases and is not stored in normal Git history.

Download:

[`CapstoneAirstrikeVisualizer.exe`](https://github.com/Gdhf/faa-wildlife-strike-damage-analysis/releases/download/v1.0.0/CapstoneAirstrikeVisualizer.exe)

The full release page is available at:

https://github.com/Gdhf/faa-wildlife-strike-damage-analysis/releases/tag/v1.0.0

and place it in this directory:

`godot/builds/CapstoneAirstrikeVisualizer.exe`

The Streamlit dashboard will automatically enable the visualization
buttons when the executable is present.
